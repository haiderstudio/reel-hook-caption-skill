# reel-hook-caption-skill

Write the words for one reel: three hooks, one
caption, and a five-slide carousel outline. One job:
take the topic and the key points the creator gives
you, and turn them into text the creator can film
and post. The output is text. Nothing is posted,
scheduled, or published for you.

## When to use this skill

Use it when the user asks to:
- Write hooks for a reel or short video.
- Write a caption for a reel or short video.
- Plan a carousel that goes with a reel — a
  five-slide outline, one point per slide.
- Do all three at once for one reel: hooks, caption,
  and carousel outline.

## When NOT to use it

- Do not use it to post, schedule, or publish
  anything. This skill writes text. The creator
  posts it, in their own name, when they choose.
  If the user wants posting or scheduling, say so
  plainly and stop — that is a different job.
- Do not use it to promise reach, views, or
  followers. No hook or caption can promise that.
  If the user asks for a promise, say "I cannot
  promise reach" and write the text anyway, with
  no promise in it.
- Do not use it to write about a topic you were not
  given. If there is no topic, say "I need a topic
  and at least 3 key points" and stop.
- Do not use it to edit or render video. Hooks,
  captions, and slide text are the whole output.
  Cutting, captions on the video itself, music,
  and rendering are different jobs.
- Do not use it as a full content plan. One reel is
  the whole job. A week of reels is a different job.

## What you need before you start

The user must give you two things:

1. **A topic** — one line, what the reel is about.
2. **At least 3 key points** — the facts the reel
   covers, in the creator's own words. These are
   the only facts you may use.

If you have fewer than 3 key points, stop and ask
for the missing ones. Write nothing — no hooks, no
caption, no slides — until you have 3. A hook built
on a point nobody gave you is invented, and an
invented point in a reel is a lie the creator has
to film.

## Workflow

### 1. Read the topic and the points

Read the topic and every key point. Write down:

- Every number in the points (times, counts,
  amounts). These are the only numbers you may
  use. A number that is not in the points is
  invented — never write it.
- Every name in the points. These are the only
  names you may use.

If a point is vague ("it saves time", "it works
well"), do not sharpen it into a number. Keep it
vague, or ask the creator for the number. A
sharpened number is an invented number.

### 2. Write 3 hooks, each a different angle

Write exactly 3 hooks. Each hook is one line,
under 100 characters, and each one takes a
different angle:

1. **A claim with a number.** The plainest hook:
   the topic, with the number from the points in
   it. Example: "I cut my editing time from 6
   hours to 47 minutes."
2. **A question or a command.** Talk to the viewer
   directly. Example: "Stop editing your video in
   the wrong order."
3. **A mistake or a skipped step.** Name what
   people get wrong, from the points. Example:
   "The screen test most buyers skip."

Rules for every hook:

- One line, under 100 characters. Count them.
- Concrete: it must name a number, a name, or a
  thing from the points. A hook with nothing
  concrete in it ("You will not believe this") is
  not a hook, it is a tease — rewrite it.
- The video must deliver what the hook says. If
  the hook promises something the points do not
  cover, it is a lie — rewrite it.
- No reach promise in a hook. No "everyone will
  watch this", no follower promise, no view
  promise.

### 3. Write one caption

The caption has four parts, in this order:

1. **First line: one of the hooks.** Pick one of
   the three — the one that fits the video best —
   and put it first, word for word. Say which one
   you picked ("Caption opens with hook 1").
2. **Body: the points, in plain words.** One
   short line per point, in the same order as the
   points were given. Use only the points. No new
   fact, no new number, no new claim.
3. **One ask, and only one.** Pick one: comment,
   save, share, or follow. One ask, in one line.
   Never two asks ("comment and follow and share"
   is three asks — pick one).
4. **Hashtags: at most 5.** Each hashtag must be
   a word from the topic or the points — a word
   the creator already used. Never a hashtag for
   a word that is not in the topic or the points.

Then check the caption:

- Total length: at most 2,200 characters. Count
  it and write the count under the caption.
- First 125 characters: write them out, with the
  count, under the caption. That is what the feed
  shows before the "... more" cut, so the creator
  can see where it cuts. The first line must end
  cleanly, not cut off mid-thought — if it does,
  shorten the first line.

### 4. Write the 5-slide carousel outline

Exactly 5 slides, one idea per slide, one line of
text per slide:

1. **Cover** — the hook you picked for the
   caption, word for word.
2. **Point 1** — the first key point, in one line.
3. **Point 2** — the second key point, in one
   line.
4. **Point 3** — the third key point, in one line.
   If there are more than 3 points, fold the extra
   points into slides 2–4 where they fit, or say
   which point was left out and why. Never add a
   6th slide.
5. **Payoff** — the last point, or the result of
   the points, plus the same one ask as the
   caption, in one line.

Rules for every slide:

- One line of text per slide, under 120
  characters. Count them.
- One idea per slide. A slide with two ideas is
  two slides — split it, or cut one idea.
- Slide text uses only the points. No new fact,
  no new number.

### 5. Write the output, then stop

Write the output in this fixed shape, and no other
shape:

```markdown
Topic: <topic>
Hooks (3):
1. <hook, under 100 characters>
2. <hook, under 100 characters>
3. <hook, under 100 characters>
Caption (opens with hook <n>):
<first line — the hook, word for word>
<body — one short line per point>
<one ask, one line>
<#hashtag ... — at most 5>
Caption length: <number> / 2200 characters
First 125 characters: "<the first 125 characters>" (<number> characters)
Slides (5):
1. Cover — <text, under 120 characters>
2. <text, under 120 characters>
3. <text, under 120 characters>
4. <text, under 120 characters>
5. Payoff — <text, under 120 characters>
```

Then stop. Do not post it, do not schedule it, do
not write a second version unless asked. The text
is the output.

## Good examples

A full reel — topic, 4 points, 3 hooks, one
caption, 5 slides (full worked example: the input
in `examples/editing-time-input.md`, the output in
`examples/editing-time-output.md`):

```markdown
Topic: How I cut my editing time from 6 hours to 47 minutes
Hooks (3):
1. I cut my editing time from 6 hours to 47 minutes.
2. Stop editing your video in the wrong order.
3. The first cut I make has nothing to do with colour.
Caption (opens with hook 1):
I cut my editing time from 6 hours to 47 minutes.
I edit in watch order: hook first, then the middle, then the ending.
First, cut pauses and dead air before colour or music.
One caption style for the whole video — I never re-decide it.
Export a draft, watch it once on my phone, fix only what I notice.
Save this for your next edit.
#editing #video #caption
Caption length: 357 / 2200 characters
First 125 characters: "I cut my editing time from 6 hours to 47 minutes.
I edit in watch order: hook first, then the middle, then the ending.
First," (125 characters)
Slides (5):
1. Cover — I cut my editing time from 6 hours to 47 minutes.
2. Edit in watch order: hook first, then the middle, then the ending.
3. Cut pauses and dead air before colour or music.
4. One caption style for the whole video.
5. Payoff — Export a draft, watch it once on my phone, fix only what you notice. Save this for your next edit.
```

Three hooks, three different angles: a claim with a
number, a command, a skipped step. The caption opens
with hook 1, the body is the four points in order,
one ask, three hashtags — all words from the topic
and points. The first 125 characters end at a word
end ("First,"), and the first line itself ends
cleanly at 49 characters, well before the feed cut.

A second reel — a different topic, 3 points
(full worked example: `examples/used-phone-input.md`
and `examples/used-phone-output.md`):

```markdown
Topic: Three things I check before I buy a used phone
Hooks (3):
1. Three checks before you buy a used phone.
2. Battery under 80%? I walk away.
3. The screen test most buyers skip.
Caption (opens with hook 1):
Three checks before you buy a used phone.
Battery health under 80% and I just walk away.
Test call and a voice note — mic and speaker checked.
Screen in full sunlight: dead pixels and a dim patch.
Comment CHECK and I will send you the list.
#phone #battery #screen
Caption length: 264 / 2200 characters
First 125 characters: "Three checks before you buy a used phone.
Battery health under 80% and I just walk away.
Test call and a voice note — mic and" (125 characters)
Slides (5):
1. Cover — Three checks before you buy a used phone.
2. Battery health under 80%? Walk away.
3. Test call and a voice note: mic and speaker.
4. Screen in full sunlight: dead pixels and dim patches.
5. Payoff — Three checks, no surprises. Comment CHECK for the list.
```

The same shape, a different topic. The caption ask
is "comment", the slide 5 ask is the same ask.

Too few points — the skill stops and asks (full
worked example: `examples/too-few-points-input.md`
and `examples/too-few-points-output.md`):

```markdown
I need one more key point before I write anything — you gave 2, I need at least 3. What is the third point?
```

No hooks, no caption, no slides. Two points is not
enough to fill three hooks and five slides without
inventing a third point, so the skill writes
nothing instead.

## Bad examples (do not write like this)

> Writes a hook with a number nobody gave you.

"I cut my editing time by 90%." The points said 6
hours to 47 minutes — 90% is a new number, worked
out or guessed, and it is not in the points. Use
the numbers you were given, word for word.

> Writes a caption with two asks.

"Comment CHECK and follow for more and save this."
That is three asks. Pick one. A caption with three
asks asks for nothing — the reader does none of
them.

> Writes a hook that promises reach.

"This hook will get you thousands of views." No
hook can promise that. Write the hook, say nothing
about what it will get.

> Writes a hashtag for a word that is not in the topic or the points.

The topic is editing time and the hashtag is
#contentcreator. That word is nowhere in the topic
or the points. Hashtags come from words the creator
already used, nothing else.

> Writes 6 slides because there were 4 points.

Five slides is the shape. Four points fit into
slides 2–4 and the payoff — fold one in, or say
which point was left out. A 6th slide breaks the
shape the creator planned around.

> Writes the hooks and posts the reel.

The skill writes text. Posting is the creator's
job, in their own name, when they choose. Never
post, never schedule, never say a reel is live.

## Output rules

- Output one reel per topic, in its own code block,
  in the fixed shape above.
- Exactly 3 hooks, exactly 1 caption, exactly 5
  slides. Never 2 hooks, never 6 slides.
- Every hook under 100 characters. Every slide
  line under 120 characters. Count them, do not
  guess.
- Every number in the output must be a number from
  the topic or the points. No new numbers.
- Every hashtag must be a word from the topic or
  the points. At most 5 hashtags.
- The caption is at most 2,200 characters. Write
  the count. Write the first 125 characters.
- One ask only, the same ask in the caption and in
  slide 5.
- Never claim a hook or caption will bring reach,
  views, or followers. Never write a reach promise
  in the output, in any words.

## Limits and safety rules

- This skill writes text, on this machine only. It
  sends nothing anywhere, posts nothing, schedules
  nothing, needs no API key, and installs no tool.
  It works from the topic and key points the user
  gives it, nothing else.
- It never invents a fact, a number, a name, or a
  result. If a point is missing, it asks for it. If
  a number is missing, it does not sharpen a vague
  point into one.
- It never promises reach, views, or followers, in
  any words. A hook is a line of text, not a
  promise about what the line will do.
- It writes one reel at a time. A week of reels, a
  full account plan, and a posting schedule are
  different jobs.
- All topics and points in this repo's examples are
  made-up sample text. Never put a real person's
  account, a real post, or a real result in an
  example, a test, or an output.
