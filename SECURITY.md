# Security Policy

This skill writes text from the topic and key points
the user gives it. It sends nothing anywhere, posts
nothing, schedules nothing, publishes nothing, edits
no file, writes no code, installs no tool, and needs
no API key or secret. It never promises reach, views,
or followers.

If you find a case where it could do otherwise, please
open an issue describing the exact input. Do not
include any real secret in the report.
